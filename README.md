# スマートフォンセンサー比較ツール

スマホのカメラセンサー（センサーサイズ・F値・焦点距離など）を並べて比較する Android アプリです。総受光量の関係をグラフで確認できます。

公開ページ: https://porarrirr.github.io/sumaho-hikaku/

## 機能

- センサーサイズ / 焦点距離 / F値から総光量を比較
- 最大 5 台 × 4 レンズの同時比較
- プリセットの保存・呼び出し
- 分数表記（例: `1/1.28`）のカスタムセンサー
- 結果の数値サマリーとエクスポート

## ビルド

```bash
./gradlew assembleDebug
./gradlew test
```

`ios/` には関連する iOS 向け作業用ディレクトリがあります。
