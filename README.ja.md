# スマートフォンセンサー比較

[English](README.md) | 日本語

スマートフォンのカメラセンサー、F値、35mm判換算焦点距離を並べて比較するAndroidアプリです。同じ画角で使われる有効センサー面積と理論上の相対受光量を計算し、複雑なカメラ仕様を比較しやすくします。

公開ページ: https://porarrirr.github.io/sumaho-hikaku/

## 主な機能

- 最大5台・各4レンズを同時比較
- 光学ズーム区間とデジタルクロップ区間を分けて計算
- `1/1.28` などの分数表記でカスタムセンサーを入力
- 比較プリセットの保存・呼び出し
- 数値サマリーの確認と結果のエクスポート

## 結果の見方

アプリの総光量は、測定したルーメン値や実写画質を直接示すものではなく、有効センサー面積とF値から求める無次元の比較指標です。

$$L_{relative}=\frac{A_{effective}}{N^2}$$

レンズ透過率、量子効率、カラーフィルター、読み出しノイズ、HDR処理、露光時間、手ぶれ補正、周辺減光、メーカーの画像処理などは考慮しません。共通の前提で幾何条件と絞りを比較するために使い、重要な判断では実写例と一次資料も確認してください。

センサーデータは [`app/src/main/res/raw/sensor_database.csv`](app/src/main/res/raw/sensor_database.csv) で管理しています。現時点では全行の一次資料URLを保持していないため、引用や判断に使う場合はメーカー資料などで再確認してください。
